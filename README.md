# 📈 Multiple Regression Investment Prediction

## 📌 Overview
This project demonstrates the implementation of a **Multiple Linear Regression Model** for investment prediction and data analysis using Machine Learning techniques. The system analyzes multiple independent variables to predict investment-related outcomes and evaluate feature significance using statistical regression analysis.

The project follows a complete Machine Learning workflow, including:
- Data preprocessing
- Categorical data encoding
- Model training and testing
- Prediction analysis
- Feature selection using Ordinary Least Squares (OLS)

The primary objective of this project is to build a predictive regression model capable of analyzing investment data and identifying the most significant variables affecting prediction performance.
